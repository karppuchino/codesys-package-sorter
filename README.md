# Conveyor System on Codesys

## Project description

This project is a simulation of a smart conveyor belt in a logistics center implemented in the CodeSys environment. 
The project demonstrated core concepts including:
- Conveyor control
- Automated product handling
- Industrial safety functions
- HMI (Human Machine Interface) desing
- Real-Time monitoring

## Technologies
- **CodeSys V3.5** - PLC programming
- **Structured Text (ST)** -Programming language
- **CodeSys Visualization** - HMI-user interface
  
## Functionalities
- Controlling the conveyor belt
- Automated generation of products/packages
- Sorts packages automatically into 3 categories (small/medium/large) based on size
- Counters and indicator lights
- Emergency stop and reset
- HMI-user interface

## Installation 
1. Download and install Codesys
2. Open the project file in Codesys
3. Login -> Start
4. Start the conveyor belt and watch the simulation.
